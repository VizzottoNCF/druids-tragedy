# Como Baixar

Para baixar basta ir para a página do [Itch.io](https://exoticlittle.itch.io/druids-tragedy) e clicar no botão de **Download**. Após isso, basta apenas extrair o arquivo de pasta .zip e rodar o executável `Druid's Tragedy.exe`.

# 📋 Premissa

**Druid's Tragedy** é um jogo de cartas que busca misturar a experiência de deck building roguelikes e mecânicas relacionadas a reflexos e tempo de reação.
O jogador toma o papel de uma druída que busca encontrar a pessoa responsável pela corrupção da floresta, enfrentando plantas e animais que foram corrompidos em suas formas mais perversas.

### Pré-requisitos
- Windows
- Mouse e Teclado com as setinhas
